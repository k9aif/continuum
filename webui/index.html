k9x Continuum — Help

What is k9x Continuum?

A governed catalog of Architecture Building Blocks (ABBs) and Solution Building Blocks (SBBs) built with k9-aif. Track who built what, which ABB contracts they implement, and which applications use them.

Tabs

SBBs Browse and publish reusable agent/squad/orchestrator components
ABBs View the contract catalog — Foundation and Common Systems building blocks
Applications Register apps that use k9-aif — track adoption across projects
Users Manage team members and their roles

Roles

Admin Full access — manage users, promote SBBs, delete anything
Developer Publish SBBs, register apps, browse catalog
Analyst Browse and search only — no publish or delete

Inspect Gate

An SBB cannot be published unless k9aif inspect has passed — confirming it complies with its ABB contract. Only published SBBs can be promoted to the shared catalog.

Continuum Levels

Foundation Core ABBs — BaseAgent, BaseOrchestrator, BaseSquad…
Common Systems OOB loop agents — K9ValidationLoopAgent, K9PlanningLoopAgent…
Industry Domain-specific reusable patterns (coming)
